# RAW.FILMS — Автономный сайт-портфолио

Полная независимая копия сайта **RAW.FILMS** (ранее размещённого на конструкторе wfolio: `billy-fox-rf.wfolio.pro`).

Сайт полностью освобождён от привязки к платному конструктору, не требует абонентской платы и готов к бесплатному размещению на любом хостинге.

---

## 🎯 Что сделано

1. **Полная автономия от wfolio**:
   - Все изображения, обложки треков, постеры видео, логотип и фоновое видео (`showreel.mp4`) выгружены локально в папку `assets/`.
   - Удалены все внешние счётчики, трекеры, скрипты блокировок и баннеры wfolio.
   - Никаких скрытых ежемесячных платежей — сайт принадлежит вам на 100%.

2. **Сохранены все страницы и разделы**:
   - **`index.html` (SHOWREEL)** — Главный экран с полноэкранным видеофоном, кнопками быстрого перехода к клипам и обложкам.
   - **`musicvideo.html` (МУЗЫКАЛЬНЫЕ ВИДЕО)** — Сетка клипов (YouTube и VK Video) с интерактивным видеоплеером в модальном окне (Lightbox).
   - **`shorts.html` (КОРОТКИЕ ВИДЕО)** — 9 вертикальных видео и клипов ВКонтакте в адаптивной сетке (соотношение 9:16).
   - **`page.html` (КОНЦЕРТНЫЕ ВИДЕООТЧЁТЫ)** — Видеоотчёты с концертов (BLAZERBOE, LeanJe, FAUNA FEST) с постерами и просмотром.
   - **`proekty.html` (ПРОЕКТЫ)** — Кейс по развитию TikTok-аккаунта студии FAUNA MUSIC (скриншот статистики, описание).
   - **`cover.html` (ДИЗАЙН ОБЛОЖЕК)** — Галерея из 8 обложек музыкальных релизов в высоком разрешении с зумом по клику.
   - **`o-sebe.html` (О СЕБЕ)** — Информация о Равиле, объединении FAUNA и список артистов (KLAVA BRAVO, Копюшон Ноу Мо, TREZV, BLAZERBOE, DABAGA, MonoRaga, KILLAWHAT, ex1ord, НомерА).

3. **Интерактивные функции (`assets/js/main.js`)**:
   - Адаптивное меню-гамбургер для мобильных устройств.
   - Видеоплеер-модалка: при открытии видео запускается воспроизведение, при закрытии — мгновенно останавливается звук.
   - Лайтбокс для обложек: просмотр полноразмерных артов по клику.
   - Плавающая кнопка «Поделиться»: копирует адрес страницы в буфер и показывает уведомление.
   - Кнопка «Наверх»: плавная прокрутка к началу страницы.
   - Прямые ссылки на контакты: Telegram (`+79322356699`) и VK (`raw.films`).

4. **SEO и чистые URL**:
   - Добавлены файлы конфигурации `_redirects` (для Cloudflare Pages / Netlify), `vercel.json` (для Vercel) и `.htaccess` (для Apache / традиционного хостинга) для работы красивых адресов без `.html` (например, `/musicvideo` вместо `/musicvideo.html`).

## 🚀 Как запустить локально прямо сейчас

1. **Простой способ**: просто откройте файл `index.html` двойным кликом в любом браузере (Chrome, Edge, Firefox, Safari).
2. **Через локальный веб-сервер**:
   Откройте терминал в папке сайта и выполните:
   ```bash
   python -m http.server 8080
   ```
   И перейдите в браузере по адресу: [http://localhost:8080](http://localhost:8080)

## 🌐 Где и как бесплатно опубликовать сайт (0 ₽ в месяц)

Вам больше не нужно платить абонентскую плату конструкторам сайтов. Этот статический сайт можно разместить на современных бесплатных платформах:

### Вариант 1: Cloudflare Pages (Рекомендуется — самый быстрый и надёжный)
1. Зарегистрируйтесь бесплатно на [cloudflare.com](https://cloudflare.com).
2. Перейдите в раздел **Workers & Pages** -> **Create application** -> **Pages**.
3. Выберите **Upload assets** (просто перетащите папку `rawfilms_site`).
4. Нажмите **Deploy site** — ваш сайт моментально станет доступен в сети!
5. Можно в 1 клик привязать свой собственный домен (например, `billy-fox.ru` или `rawfilms.ru`), и Cloudflare бесплатно выдаст вечный SSL-сертификат (https).

### Вариант 2: GitHub Pages
1. Создайте бесплатный репозиторий на [github.com](https://github.com).
2. Загрузите файлы сайта в репозиторий.
3. В настройках репозитория (**Settings** -> **Pages**) выберите ветку `main` и сохраните.
4. Сайт будет работать по бесплатному адресу `ваш-логин.github.io/rawfilms_site/` или на вашем личном домене.

### Вариант 3: Обычный хостинг (Beget, TimeWeb, Reg.ru)
Если у вас уже есть любой виртуальный хостинг:
1. Зайдите в файловый менеджер или по FTP.
2. Загрузите содержимое папки `rawfilms_site` в папку вашего сайта (`public_html` или `httpdocs`).
3. Файл `.htaccess` уже настроен для красивых URL.

## ✏️ Как редактировать и добавлять контент

- **Добавить новое видео в клипы**: откройте `musicvideo.html`, найдите блок `<section class="video-grid">` и добавьте карточку с ссылкой на YouTube/VK видео.
- **Добавить новую обложку**: положите файл картинки в `assets/images/covers/` и добавьте блок в `cover.html`.
- **Изменить контакты / соцсети**: внизу каждого HTML-файла в блоке `<footer>` ссылки на Telegram и ВКонтакте.
